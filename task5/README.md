# Python Basic Programs

This assignment contains two Python tasks.

## Task 1: Student Dictionary Program

* Creates a dictionary with student names and marks
* Takes user input for student name
* Displays marks if found
* Shows "Student not found" if name does not exist

Run:
python task5.1_dict.py

## Task 2: List Operations Program

* Creates a list from 1 to 10
* Extracts first five elements using slicing
* Reverses the extracted elements
* Prints original, extracted, and reversed list

Run:
python task5.2_slice.py
